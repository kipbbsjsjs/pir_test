# pir_test — ESP32 PIR 人体红外检测台

毕业设计《基于 ESP32 的洗车工位喷淋控制系统》的 PIR 单元测试程序。
用于验证 HC-SR501 人体红外传感器，并现场调整其灵敏度 / 延时电位器。

## 功能

- ESP32 自建热点（免路由器），手机直连查看网页检测台
- 网页实时显示：有人/无人大字状态、24 秒输出波形（每格 250ms）、触发次数、事件日志
- SSE 长连接推送，边沿 50ms 检测即推，端到端延迟约 50ms；SSE 失败自动降级为 300ms 轮询
- OLED 本地同步显示 + LED 指示（检测到人点亮）
- 触发/恢复边沿事件同步打印串口（115200）

## 接线

| HC-SR501 | ESP32 |
|----------|-------|
| VCC      | 5V（VIN） |
| OUT      | GPIO16（丝印 RX2） |
| GND      | GND |

| LED | ESP32 |
|-----|-------|
| 阳极（经 220Ω） | GPIO4 |
| 阴极 | GND |

| OLED 0.96" I2C | ESP32 |
|----------------|-------|
| VDD | 3.3V（禁接 5V） |
| SDA | GPIO21 |
| SCL | GPIO22 |

原理图：[人体红外检测感应器.eprj2](人体红外检测感应器.eprj2)（嘉立创EDA专业版工程文件，SQLite 格式）

## 使用

1. Arduino IDE（ESP32 板卡包 + Adafruit SSD1306 / GFX / BusIO 库）烧录
2. 手机连接热点 `PIR-TestBoard`（密码 `12345678`）
3. 浏览器打开 http://192.168.4.1

## 踩坑记录

- HC-SR501 必须 VCC/OUT/GND 三根线完整连接，两线"能出数据"是寄生供电的假信号
- 模块背面丝印是镜像方向，接线以正面丝印为准，VCC/GND 接反会输出恒高
- 延时电位器（Tx）逆时针拧到底为最短延时，灵敏度电位器（Sx）过高会把呼吸起伏都当触发
- 上电需约 60 秒预热稳定
